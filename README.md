# IGP - Service SSE

Application mobile de saisie des inspections générales planifiées (IGP 1 à 4, Cantine) : cotation C / PC / NC / NA, photos, export Excel. Fonctionne hors ligne une fois installée.

Le contenu (checklists et modèle Excel) est chiffré : l'accès demande le code fourni par le service SSE.
